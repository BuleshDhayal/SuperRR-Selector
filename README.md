# SuperRR Selector

Rajasthan Royals IPL 2027 auction intelligence and historical pressure-performance research dashboard.

## Features
- Historical batter and bowler rankings
- IPL 2027 RR retained squad
- Released-player profiles and screening
- Separate provisional RR auction hypotheses
- Player profile explorer
- Auction squad builder

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

Hosted using Streamlit Community Cloud.

Historical rankings and user-provided auction hypotheses are separate.
Previous salaries are not auction-price predictions.
